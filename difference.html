Can a momentum strategy outperform broker picks?

A matched-date study comparing a rules-based stock basket with broker Buy recommendations over the same 60-trading-session period.

Research question

On dates with usable price data, does the strategy’s equal-weight basket earn a higher 60-session return than the broker Buy basket?

Study design / 04

How the comparison works

01 / MATCH

Build same-date baskets

For each report date, combine unique matched stock symbols with a Buy, Strong Buy, Accumulate, Add, or Outperform rating. Each broker basket contains the recommendations available for that date.

02 / SELECT

Apply the strategy rules

Use only price history available before entry. Keep stocks passing the trend and momentum checks below, rank them by six-month momentum, then select the same number of stocks as in the broker basket.

03 / MEASURE

Compare the next 60 sessions

Enter on the next trading session and measure adjusted-close return after 60 sessions. Deduct the same 0.2 percentage-point round-trip cost from both baskets. A date is a win only when one basket beats the other by more than 0.05 pp.

Strategy rule

Price > SMA(50) > SMA(200); positive 126-session momentum; MACD above its signal line; and ADX(14) at least 20. Rank qualifying stocks by 126-session momentum. ADX measures trend strength, while the price and moving-average rules set the upward direction. Indicator calculations follow the standard definitions from MACD and ADX.

How to read these results

Checking repeated selections…

The filter was chosen using these same dates, so the result is in-sample. The 60-session windows overlap, repeated stocks can drive several rows, and returns are not cumulative live-portfolio returns. The downloaded price universe may have survivorship bias, and the broker snapshot is partial.
